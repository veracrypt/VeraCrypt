文档 命令行使用 Linux 和 macOS

Linux 和 macOS 命令行使用

本节适用于类 Unix 系统（包括 Linux 和 macOS）上的 VeraCrypt。Windows 命令行语法在 Windows 命令行使用中单独记录。

要在终端中显示已安装 VeraCrypt 版本的命令行帮助，请运行：

veracrypt -t --help

-t 或 --text 选项选择文本用户界面，必须作为第一个参数指定。没有 -t 时，veracrypt --help 在图形用户界面可用时可能会显示图形帮助窗口。

语法

veracrypt [选项] 命令

veracrypt [选项] 卷路径 [挂载目录]

如果未指定显式命令但给出了卷路径，VeraCrypt 将挂载该卷。省略 挂载目录 时，VeraCrypt 使用默认挂载目录。

命令

--auto-mount=devices|favorites 自动挂载设备托管的卷、收藏卷，或在用逗号组合时同时挂载两者。
--backup-headers [卷路径] 将卷头备份到文件。命令行中未指定的必需值将向用户请求。
-c 或 --create [卷路径] 创建新卷。如果未在命令行中指定，大多数值将向用户请求。另请参阅 --encryption、--filesystem、--hash、--keyfiles、--password、--pim、--random-source、--quick、--size 和 --volume-type。
--create-keyfile [文件路径] 创建包含伪随机数据的新密钥文件。
-C 或 --change [卷路径] 更改卷密码、PIM、密钥文件和/或头密钥派生算法。另请参阅 --hash、--new-hash、--new-keyfiles、--new-password、--new-pim、--password、--pim 和 --random-source。
-u 或 --unmount [已挂载卷]
-d 或 --dismount [已挂载卷]		 卸载已挂载的卷。如果未指定已挂载的卷，则卸载所有已挂载的 VeraCrypt 卷。--dismount 已弃用；请使用 --unmount。
--delete-token-keyfiles 从安全令牌删除密钥文件。
--export-token-keyfile 从安全令牌导出密钥文件。
--import-token-keyfiles 将密钥文件导入安全令牌。另请参阅 --token-lib。
-l 或 --list [已挂载卷] 显示已挂载的卷。默认情况下，仅显示卷路径、虚拟设备和挂载点。使用 --verbose 获取更多详细信息。
--list-token-keyfiles 显示所有可用的令牌密钥文件。
--list-securitytoken-keyfiles 显示所有可用的安全令牌密钥文件。
--list-emvtoken-keyfiles 显示所有可用的 EMV 令牌密钥文件。
--mount [卷路径] 交互式挂载卷。卷路径和缺失的选项将向用户请求。
--restore-headers [卷路径] 从嵌入式备份头或外部备份文件恢复卷头。
--save-preferences 保存用户偏好设置。
--test 测试加密和解密过程中使用的内部算法。
--version 显示 VeraCrypt 版本信息。
--volume-properties [已挂载卷] 显示已挂载卷的属性。

已挂载卷

已挂载的卷可以使用以下任一形式指定：

  • 加密 VeraCrypt 卷的路径。
  • 卷文件系统的挂载目录（如果已挂载）。
  • 已挂载卷的插槽号（与 --slot 一起使用时）。

选项

--allow-insecure-mount 允许将卷挂载到用户 PATH 中的挂载点。
--allow-screencapture 允许将 VeraCrypt 窗口包含在屏幕截图和屏幕录制中。此选项适用于 macOS 版本。
--background-task 启动 VeraCrypt 后台任务。
--display-password 输入时显示密码字符。
--encryption=加密算法 创建新卷时使用指定的加密算法。对于级联，请使用 VeraCrypt 显示的算法名称，例如 AES-Twofish。
--explore 挂载卷后打开文件管理器窗口。
--filesystem=类型 挂载或创建的文件系统类型。挂载时，该类型传递给系统挂载命令。none 禁用文件系统挂载或创建。在 Linux 上，ntfs3 固定内核 ntfs3 驱动程序并绕过挂载辅助程序，而 kernel-ntfs 选择可用的内核 NTFS 驱动程序（ntfs 或 ntfs3）。这些 Linux 驱动程序选择器仅用于挂载；创建新 NTFS 卷时请使用 NTFS。支持的创建类型取决于平台：Linux 支持 FAT、Ext2、Ext3、Ext4、NTFS、exFAT 和 Btrfs；macOS 支持 FAT、HFS/HFS+/MacOsExt、exFAT 和 APFS；FreeBSD 和 Solaris 版本支持 FAT 和 UFS。非 FAT 创建需要相应的系统格式化程序可用。
-f 或 --force 强制挂载正在使用的卷、卸载正在使用的卷，或覆盖文件。具体效果取决于操作系统。
--fs-options=选项 使用 -o 传递给系统挂载命令的文件系统挂载选项。此选项在 Linux 和其他支持的类 Unix 版本上可用，但在 macOS 上不可用。
--hash=哈希算法 挂载、创建卷或更改密码/密钥文件时使用指定的头密钥派生算法。此选项还在适用时指定随机数生成器的混合哈希。
-h 或 --help 显示详细的命令行帮助。
-k 密钥文件1[,密钥文件2,...] 或 --keyfiles=密钥文件1[,密钥文件2,...] 使用指定的密钥文件。指定目录时，将非递归地使用其中的所有文件。使用双逗号（,,）表示密钥文件名中包含逗号。存储在安全令牌上的密钥文件可以指定为 token://slot/插槽号/file/文件名；EMV 令牌密钥文件可以指定为 emv://slot/插槽号。使用 -k "" 禁用交互式密钥文件提示。
--legacy-password-maxlength 使用 64 UTF-8 字节的传统最大密码长度。
--load-preferences 在处理命令行选项之前加载用户偏好设置，允许命令行选项覆盖偏好设置。
-m 选项1[,选项2,...] 或 --mount-options=选项1[,选项2,...] 设置 VeraCrypt 卷挂载选项。支持的选项有 headerbak、nokernelcrypto、readonly 或 ro、system 以及 timestamp 或 ts。在 Linux 上，kernelntfs 在检测到 NTFS 且未提供文件系统类型时，为当前挂载启用内核 NTFS 驱动程序选择。
--new-hash=哈希算法 更改卷密码或密钥文件时设置新的头密钥派生算法。此选项与 --change 一起使用。
--new-keyfiles=密钥文件1[,密钥文件2,...] 更改卷密码或密钥文件时设置新的密钥文件。此选项与 --change 一起使用。
--new-password=密码 更改卷密码或密钥文件时设置新密码。此选项与 --change 一起使用。
--new-pim=PIM 更改卷密码或密钥文件时设置新的 PIM。此选项与 --change 一起使用。
--no-size-check 禁用验证请求的容器大小与可用磁盘空间的检查。
--non-interactive 不与用户交互。此选项仅在文本模式下支持。
-p 密码 或 --password=密码 使用指定的密码挂载或打开卷。空密码可以用 -p "" 指定。
--pim=PIM 使用指定的 PIM 挂载或打开卷。
--protect-hidden=yes|no 挂载外层卷时写保护隐藏卷。如果启用，VeraCrypt 使用隐藏卷凭据确定隐藏区域并保护其免受写入。
--protection-hash=哈希算法 为受 --protect-hidden=yes 保护的隐藏卷使用指定的头密钥派生算法。
--protection-keyfiles=密钥文件1[,密钥文件2,...] 为受 --protect-hidden=yes 保护的隐藏卷使用指定的密钥文件。
--protection-password=密码 为受 --protect-hidden=yes 保护的隐藏卷使用指定的密码。
--protection-pim=PIM 为受 --protect-hidden=yes 保护的隐藏卷使用指定的 PIM。
--quick 创建普通文件托管或设备托管卷时启用快速格式化。创建外层卷时请勿使用此选项。在文本模式下，VeraCrypt 无法推断普通卷是否打算成为外层卷。对于文件容器，快速格式化可能会创建稀疏或未写入的主机区域。分配行为取决于主机文件系统稀疏文件支持，如果主机文件系统空间不足，后续写入可能会失败。
--random-source=文件 使用指定的文件作为随机数据源，例如创建卷时。
--slot=插槽 挂载、卸载、列出或显示卷属性时使用指定的插槽号。
--size=大小[K|KiB|M|MiB|G|GiB|T|TiB] 或 --size=max 创建新卷时使用指定的大小。如果未指定后缀，则以字节为单位解释该值。max 使用所有可用的空闲空间。
--stdin 从标准输入读取密码。此选项只能与 --non-interactive 一起使用，不能与 --password 组合使用。
-t 或 --text 使用文本用户界面。此选项必须作为第一个参数指定。
--token-lib=库路径 使用指定的 PKCS #11 安全令牌库。
--token-pin=PIN 使用指定的安全令牌 PIN。
--use-dummy-sudo-password 在 sudo 中使用虚拟密码来检测 sudo 是否已经过身份验证。此选项在 Linux 和 FreeBSD 版本上可用。
-v 或 --verbose 启用详细输出。
--volume-type=normal|hidden 创建新卷时使用指定的卷类型。

安全说明

在命令行上传递密码、PIM、令牌 PIN 或隐藏卷保护密码可能不安全，因为命令行参数可能在进程列表、shell 历史记录或系统日志中可见。如果可能，请让 VeraCrypt 交互式地提示输入敏感值，或在适当时使用 --stdin 和 --non-interactive。用户还必须遵守 安全要求和预防措施 中列出的安全要求。

示例

使用文本用户界面创建新卷：

veracrypt -t -c

挂载卷：

veracrypt volume.hc /media/veracrypt1

使用密钥文件以只读方式挂载卷：

veracrypt -m ro -k keyfile1,keyfile2 volume.hc /media/veracrypt1

挂载卷但不挂载其文件系统：

veracrypt --filesystem=none volume.hc

使用 Linux 内核 NTFS 驱动程序挂载 NTFS 卷：

veracrypt -t --filesystem=kernel-ntfs volume.hc /media/veracrypt1

挂载卷时仅提示输入密码：

veracrypt -t -k "" --pim=0 --protect-hidden=no volume.hc /media/veracrypt1

非交互式挂载卷并从标准输入读取密码：

printf '%s\n' "$VERACRYPT_PASSWORD" | veracrypt -t --non-interactive --stdin --pim=0 --protect-hidden=no volume.hc /media/veracrypt1

列出已挂载卷的详细信息：

veracrypt -t -v --list

卸载卷：

veracrypt -u volume.hc

卸载所有已挂载的 VeraCrypt 卷：

veracrypt -u

文本模式下创建隐藏卷

经验不足的用户应使用图形用户界面创建隐藏卷。使用文本用户界面时，必须遵循以下步骤：

  1. 创建不带文件系统且不使用 --quick 的外层卷。
  2. 在外层卷内创建隐藏卷。
  3. 使用隐藏卷保护挂载外层卷。
  4. 在外层卷的虚拟设备上创建文件系统。
  5. 挂载新文件系统并填充数据。
  6. 卸载外层卷。

如果在任何步骤中触发了隐藏卷保护，请从第一步重新开始。
