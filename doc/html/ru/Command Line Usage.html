Использование в режиме командной строки

VeraCrypt использует разный синтаксис командной строки в Windows и Unix-подобных системах. Выберите страницу для своей операционной системы:

  • Использование в режиме командной строки в Windows
  • Использование в режиме командной строки в Linux и macOS

В Linux и macOS справку по командной строке установленной сборки VeraCrypt можно также вывести в терминале командой:

veracrypt -t --help
