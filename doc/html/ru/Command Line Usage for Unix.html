Использование в режиме командной строки в Linux и macOS

Этот раздел относится к VeraCrypt в Unix-подобных системах, включая Linux и macOS. Синтаксис командной строки Windows описан отдельно в разделе Использование в режиме командной строки в Windows.

Чтобы вывести в терминале справку по командной строке установленной сборки VeraCrypt, выполните:

veracrypt -t --help

Параметр -t или --text выбирает текстовый пользовательский интерфейс и должен быть первым аргументом. Без -t команда veracrypt --help может открыть графическое окно справки, если доступен графический интерфейс.

Синтаксис

veracrypt [OPTIONS] COMMAND

veracrypt [OPTIONS] VOLUME_PATH [MOUNT_DIRECTORY]

Если явная команда не указана, но задан путь к тому, VeraCrypt монтирует том. Если MOUNT_DIRECTORY опущен, VeraCrypt использует каталог монтирования по умолчанию.

Команды

--auto-mount=devices|favorites Автоматически монтировать тома на устройствах, избранные тома или и те и другие, если значения объединены запятой.
--backup-headers [VOLUME_PATH] Сохранить резервную копию заголовков тома в файл. Необходимые значения, не указанные в командной строке, запрашиваются у пользователя.
-c или --create [VOLUME_PATH] Создать новый том. Большинство значений запрашиваются у пользователя, если не указаны в командной строке. См. также --encryption, --filesystem, --hash, --keyfiles, --password, --pim, --random-source, --quick, --size и --volume-type.
--create-keyfile [FILE_PATH] Создать новый ключевой файл, содержащий псевдослучайные данные.
-C или --change [VOLUME_PATH] Изменить пароль тома, PIM, ключевые файлы и/или алгоритм формирования ключа заголовка. См. также --hash, --new-hash, --new-keyfiles, --new-password, --new-pim, --password, --pim и --random-source.
-u или --unmount [MOUNTED_VOLUME]
-d или --dismount [MOUNTED_VOLUME]		 Размонтировать смонтированный том. Если том не указан, размонтировать все смонтированные тома VeraCrypt. Параметр --dismount устарел; используйте --unmount.
--delete-token-keyfiles Удалить ключевые файлы с токенов безопасности.
--export-token-keyfile Экспортировать ключевой файл с токена безопасности.
--import-token-keyfiles Импортировать ключевые файлы в токен безопасности. См. также --token-lib.
-l или --list [MOUNTED_VOLUME] Показать смонтированные тома. По умолчанию отображаются только путь к тому, виртуальное устройство и точка монтирования. Для подробных сведений используйте --verbose.
--list-token-keyfiles Показать все доступные ключевые файлы токенов.
--list-securitytoken-keyfiles Показать все доступные ключевые файлы токенов безопасности.
--list-emvtoken-keyfiles Показать все доступные ключевые файлы токенов EMV.
--mount [VOLUME_PATH] Смонтировать том в интерактивном режиме. Путь к тому и недостающие параметры запрашиваются у пользователя.
--restore-headers [VOLUME_PATH] Восстановить заголовки тома из встроенной резервной копии заголовка или из внешнего резервного файла.
--save-preferences Сохранить настройки пользователя.
--test Проверить внутренние алгоритмы, используемые при шифровании и расшифровке.
--version Показать информацию о версии VeraCrypt.
--volume-properties [MOUNTED_VOLUME] Показать свойства смонтированного тома.

MOUNTED_VOLUME

Смонтированный том можно указать любым из следующих способов:

  • Путь к зашифрованному тому VeraCrypt.
  • Каталог монтирования файловой системы тома, если она смонтирована.
  • Номер слота смонтированного тома при использовании --slot.

Параметры

--allow-insecure-mount Разрешить монтирование томов в точки монтирования, включённые в PATH пользователя.
--allow-screencapture Разрешить включение окон VeraCrypt в снимки и записи экрана. Этот параметр относится к сборкам для macOS.
--background-task Запустить фоновую задачу VeraCrypt.
--display-password Показывать символы пароля при вводе.
--encryption=ENCRYPTION_ALGORITHM Использовать указанный алгоритм шифрования при создании нового тома. Для каскадов используйте название алгоритма, отображаемое VeraCrypt, например AES-Twofish.
--explore Открыть окно файлового менеджера после монтирования тома.
--filesystem=TYPE Тип файловой системы для монтирования или создания. При монтировании тип передаётся системной команде монтирования. Значение none отключает монтирование или создание файловой системы. В Linux ntfs3 явно выбирает драйвер ntfs3 ядра, минуя вспомогательные программы монтирования, а kernel-ntfs выбирает доступный драйвер NTFS ядра (ntfs или ntfs3). Эти параметры выбора драйвера Linux используются только при монтировании; при создании нового тома NTFS используйте NTFS. Поддерживаемые типы создаваемых файловых систем зависят от платформы: Linux поддерживает FAT, Ext2, Ext3, Ext4, NTFS, exFAT и Btrfs; macOS — FAT, HFS/HFS+/MacOsExt, exFAT и APFS; сборки для FreeBSD и Solaris — FAT и UFS. Для создания файловой системы, отличной от FAT, необходима соответствующая системная программа форматирования.
-f или --force Принудительно смонтировать используемый том, размонтировать используемый том или перезаписать файл. Точный результат зависит от операционной системы.
--fs-options=OPTIONS Параметры монтирования файловой системы, передаваемые системной команде монтирования с ключом -o. Этот параметр доступен в Linux и других поддерживающих его Unix-подобных сборках, но не в macOS. Для защиты расшифрованного устройства от записи используйте --mount-options=ro; параметр --fs-options=ro, действующий только на файловую систему, может допускать запись при восстановлении журнала.
--hash=HASH Использовать указанный алгоритм формирования ключа заголовка при монтировании, создании тома или изменении пароля/ключевых файлов. Там, где применимо, этот параметр также задаёт хеш смешивания генератора случайных чисел.
-h или --help Показать подробную справку по командной строке.
-k KEYFILE1[,KEYFILE2,...] или --keyfiles=KEYFILE1[,KEYFILE2,...] Использовать указанные ключевые файлы. Если указан каталог, используются все файлы в нём без рекурсивного обхода. Запятую в имени ключевого файла указывайте двумя запятыми (,,). Ключевой файл на токене безопасности можно указать как token://slot/SLOT_NUMBER/file/FILENAME; ключевой файл токена EMV — как emv://slot/SLOT_NUMBER. Чтобы отключить интерактивные запросы ключевых файлов, используйте -k "".
--legacy-password-maxlength Использовать прежнюю максимальную длину пароля — 64 байта UTF-8.
--load-preferences Загрузить настройки пользователя до обработки параметров командной строки, позволяя параметрам командной строки переопределять настройки.
-m OPTION1[,OPTION2,...] или --mount-options=OPTION1[,OPTION2,...] Задать параметры монтирования тома VeraCrypt. Поддерживаются headerbak, nokernelcrypto, readonly или ro, system, а также timestamp или ts. В Linux kernelntfs включает выбор драйвера NTFS ядра для текущего монтирования, если обнаружена NTFS и тип файловой системы не указан. Защита от записи распространяется и на расшифрованное устройство, и на файловую систему. Файловая система, которой нужна запись для восстановления журнала, может отказаться монтироваться только для чтения.
--new-hash=HASH Задать новый алгоритм формирования ключа заголовка при изменении пароля тома или ключевых файлов. Используется с --change.
--new-keyfiles=KEYFILE1[,KEYFILE2,...] Задать новые ключевые файлы при изменении пароля тома или ключевых файлов. Используется с --change.
--new-password=PASSWORD Задать новый пароль при изменении пароля тома или ключевых файлов. Используется с --change.
--new-pim=PIM Задать новый PIM при изменении пароля тома или ключевых файлов. Используется с --change.
--no-size-check Отключить проверку запрошенного размера контейнера на соответствие свободному месту на диске.
--non-interactive Не взаимодействовать с пользователем. Поддерживается только в текстовом режиме.
-p PASSWORD или --password=PASSWORD Использовать указанный пароль для монтирования или открытия тома. Пустой пароль можно указать с помощью -p "".
--pim=PIM Использовать указанный PIM для монтирования или открытия тома.
--protect-hidden=yes|no Защитить скрытый том от записи при монтировании внешнего тома. Если параметр включён, VeraCrypt использует учётные данные скрытого тома, чтобы определить скрытую область и защитить её от записи.
--protection-hash=HASH Использовать указанный алгоритм формирования ключа заголовка для скрытого тома, защищённого параметром --protect-hidden=yes.
--protection-keyfiles=KEYFILE1[,KEYFILE2,...] Использовать указанные ключевые файлы для скрытого тома, защищённого параметром --protect-hidden=yes.
--protection-password=PASSWORD Использовать указанный пароль для скрытого тома, защищённого параметром --protect-hidden=yes.
--protection-pim=PIM Использовать указанный PIM для скрытого тома, защищённого параметром --protect-hidden=yes.
--quick Включить быстрое форматирование при создании обычного тома в файле или на устройстве. Не используйте этот параметр при создании внешнего тома. В текстовом режиме VeraCrypt не может определить, что обычный том впоследствии станет внешним. Для файловых контейнеров быстрое форматирование может создавать разреженные или незаписанные области в файловой системе хоста. Выделение места зависит от поддержки разреженных файлов файловой системой хоста; если место на хосте закончится, последующие операции записи могут завершиться ошибкой.
--random-source=FILE Использовать указанный файл как источник случайных данных, например при создании тома.
--slot=SLOT Использовать указанный номер слота при монтировании, размонтировании, выводе списка или свойств тома.
--size=SIZE[K|KiB|M|MiB|G|GiB|T|TiB] или --size=max Использовать указанный размер при создании нового тома. Если суффикс не указан, значение интерпретируется в байтах. Значение max использует всё доступное свободное место.
--stdin Прочитать пароль из стандартного ввода. Этот параметр можно использовать только с --non-interactive и нельзя сочетать с --password. Пароль — первая строка; завершающий перевод строки необязателен, а символ возврата каретки или байт NUL считаются частью пароля. Он декодируется в кодировке текущей локали (LC_CTYPE), затем преобразуется в UTF-8 для использования в качестве пароля тома. Пустая строка означает пустой пароль (только для ключевых файлов). Для команд, использующих пароль, отсутствие ввода, недопустимая последовательность в указанной кодировке и строка длиннее максимально допустимого пароля считаются ошибками.
-t или --text Использовать текстовый пользовательский интерфейс. Этот параметр должен быть первым аргументом.
--token-lib=LIB_PATH Использовать указанную библиотеку токена безопасности PKCS #11.
--token-pin=PIN Использовать указанный PIN-код токена безопасности.
--use-dummy-sudo-password Использовать фиктивный пароль в sudo, чтобы определить, выполнена ли уже аутентификация sudo. Этот параметр доступен в сборках для Linux и FreeBSD.
-v или --verbose Включить подробный вывод.
--volume-type=normal|hidden Использовать указанный тип тома при создании нового тома.

Примечания по безопасности

Передача пароля, PIM, PIN-кода токена или пароля защиты скрытого тома в командной строке может быть небезопасной, поскольку аргументы командной строки могут быть видны в списке процессов, истории оболочки или системных журналах. По возможности вводите конфиденциальные значения по интерактивному запросу VeraCrypt либо, где это уместно, используйте --stdin вместе с --non-interactive. Пользователи также должны соблюдать требования и меры предосторожности, перечисленные в разделе Требования безопасности и меры предосторожности.

Примеры

Создать новый том с помощью текстового интерфейса:

veracrypt -t -c

Смонтировать том:

veracrypt volume.hc /media/veracrypt1

Смонтировать том только для чтения, используя ключевые файлы:

veracrypt -m ro -k keyfile1,keyfile2 volume.hc /media/veracrypt1

Смонтировать том без монтирования его файловой системы:

veracrypt --filesystem=none volume.hc

Смонтировать том NTFS с помощью драйвера NTFS ядра Linux:

veracrypt -t --filesystem=kernel-ntfs volume.hc /media/veracrypt1

Смонтировать том с запросом только пароля:

veracrypt -t -k "" --pim=0 --protect-hidden=no volume.hc /media/veracrypt1

Смонтировать том без взаимодействия с пользователем и прочитать пароль из стандартного ввода:

printf '%s\n' "$VERACRYPT_PASSWORD" | veracrypt -t --non-interactive --stdin --pim=0 --protect-hidden=no volume.hc /media/veracrypt1

Вывести список смонтированных томов с подробными сведениями:

veracrypt -t -v --list

Размонтировать том:

veracrypt -u volume.hc

Размонтировать все смонтированные тома VeraCrypt:

veracrypt -u

Создание скрытого тома в текстовом режиме

Неопытным пользователям следует создавать скрытые тома с помощью графического интерфейса. При использовании текстового интерфейса необходимо соблюдать следующую процедуру:

  1. Создайте внешний том без файловой системы и без --quick.
  2. Создайте скрытый том внутри внешнего тома.
  3. Смонтируйте внешний том с защитой скрытого тома.
  4. Создайте файловую систему на виртуальном устройстве внешнего тома.
  5. Смонтируйте новую файловую систему и заполните её данными.
  6. Размонтируйте внешний том.

Если на любом этапе сработает защита скрытого тома, начните заново с первого шага.
